1. Что такое HTML

HTML (HyperText Markup Language) - язык гипертекстовой разметки. Это не язык программирования, а язык разметки: мы помечаем текст тегами, чтобы браузер знал, что где находится.

HTML-файл - это обычный текстовый файл с расширением .html. Браузер его читает и превращает в страницу.

В веб-разработке есть три технологии:

  • HTML - скелет, структура
  • CSS - внешний вид, оформление
  • JavaScript - поведение, интерактивность

2. Структура документа

Каждый HTML-документ состоит из обязательных частей:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Заголовок страницы</title>
</head>
<body>
    Содержимое страницы
</body>
</html>

Разбор каждой части

Часть Что значит
<!DOCTYPE html> Декларация: «это современный HTML». Пишется первой строкой
<html> Корневой элемент. Всё содержимое внутри. Сюда вешают атрибут lang
<head> Служебная часть. Пользователь её не видит
<body> Всё, что видно на странице
Важно: тег <html> нужен не только как «коробка». На него вешают атрибуты - самый частый lang. Без него некуда будет указать язык страницы.

3. Метаданные

Внутри <head> лежат метаданные - служебная информация для браузера и поисковиков. Пользователь её не видит, кроме <title>.

charset - кодировка

<meta charset="UTF-8">

Указывает кодировку файла. Всегда пишем UTF-8 - это современная кодировка, в которой есть все буквы мира.

Правило: кодировка файла и <meta charset> должны совпадать. Если сказать браузеру «я UTF-8», а файл сохранить в ANSI - получишь кракозябры.

viewport - для мобильных

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Говорит браузеру: «считай ширину экрана реальной шириной устройства». Без этого на телефоне страница будет уменьшенной копией десктопной.

description - описание

<meta name="description" content="Личная страница Ивана">

Описание страницы. Пользователь его не видит на странице, но видит в поисковой выдаче - серым текстом под заголовком.

Нюанс: description - это рекомендация, а не приказ. Google может проигнорировать ваш текст и собрать описание сам из содержимого страницы.

title - заголовок вкладки

<title>Моя первая страница</title>

Единственный элемент из <head>, который видит пользователь - на вкладке браузера. Также используется поисковиками.

4. Текст

Заголовки

Шесть уровней: от <h1> до <h6>. 

<h1>Главный заголовок</h1>
<h2>Раздел</h2>
<h3>Подраздел</h3>
Правила:
  • На странице только один <h1>
  • Нельзя перескакивать уровни: после h1 идёт h2, не h4

Абзацы и переносы

<p>Это абзац текста.</p>

<p>Первая строка<br>Вторая строка</p>

<p> - абзац, <br> - перенос строки внутри абзаца. Перенос строки в коде браузер игнорирует.

5. Форматирование текста

Теги делятся на семантические (описывают смысл) и визуальные (описывают вид).

Семантические теги

<strong>Важный текст</strong>
<em>Акцент, интонация</em>
<mark>Выделенное, искомое</mark>
<small>Второстепенная информация</small>
<del>Удалённый текст</del>
<ins>Добавленный текст</ins>
<sub>Нижний индекс</sub>
<sup>Верхний индекс</sup>

Визуальные теги

<b>Жирный</b>
<i>Курсив</i>

pre - текст как в коде

<pre>
Строка 1
    Строка 2 с отступом
</pre>

Сохраняет переносы строк и пробелы ровно так, как написано в коде.

Комментарии

<!-- Это комментарий -->

Не виден на странице, но виден в исходном коде. Используется для пометок, объяснений и временного отключения кода.

6. Списки

Маркированный список

<ul>
    <li>Хлеб</li>
    <li>Молоко</li>
    <li>Яйца</li>
</ul>

Порядок не важен. Каждый пункт с маркером.

Нумерованный список

<ol>
    <li>Разбейте яйца</li>
    <li>Взбейте с молоком</li>
    <li>Добавьте муку</li>
</ol>

Порядок важен. Каждый пункт с числом.

Вложенные списки

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
</ul>

Вложенный список кладётся внутрь <li>.

Список описаний

<dl>
    <dt>HTML</dt>
    <dd>Язык разметки гипертекста</dd>
    
    <dt>CSS</dt>
    <dd>Язык описания внешнего вида</dd>
</dl>

Пары «термин - определение»: <dt> - термин, <dd> - определение.

Когда какой использовать

Список Когда использовать
<ul> Порядок не важен: список покупок, навыков
<ol> Порядок важен: инструкция, рецепт, шаги
<dl> Пары «термин - определение»: словарь, глоссарий

7. Ссылки

Слово «гипертекст» в названии HTML - это про ссылки. Гипертекст - это текст, по которому можно переходить. Ссылки - то, что делает интернет интернетом. Без них была бы просто куча отдельных страниц.

Тег a и атрибут href

<a href="https://yandex.ru">Перейти на Яндекс</a>

Ссылка делается тегом <a> - anchor, «якорь». Адрес, куда ведёт ссылка, указывается в атрибуте href - hypertext reference.

<a> - парный тег. Текст между <a> и </a> - то, что видит пользователь. Атрибут href - куда ведёт ссылка.

Абсолютные ссылки

Полный адрес с протоколом:

<a href="https://www.google.com">Google</a>
<a href="https://github.com">GitHub</a>

Обязательно с https:// (или http://). Без протокола браузер подумает, что это относительная ссылка.

Относительные ссылки

Адрес относительно текущего файла. Используется для ссылок между страницами своего сайта.

Представьте такую структуру:

lesson-3/
├── index.html
├── about.html
└── contacts.html

Тогда ссылки между ними:

<!-- В файле index.html -->
<a href="about.html">Обо мне</a>
<a href="contacts.html">Контакты</a>

Заметьте: не https://..., а просто about.html. Браузер сам поймёт, что файл лежит рядом с текущим.

Если файл в другой папке

<!-- Файл в подпапке pages -->
<a href="pages/about.html">Обо мне</a>

<!-- Файл на уровень выше -->
<a href="../index.html">На главную</a>

../ означает «выйти на уровень выше».

Абсолютные vs относительные: какую выбирать

Ситуация Какую ссылку использовать
Ссылка на внешний сайт Абсолютная: https://yandex.ru
Ссылка внутри своего сайта Относительная: about.html
Почему не всегда абсолютные? Если сайт переедет на другой домен, все абсолютные ссылки придётся менять вручную. А относительные продолжат работать.

Якорные ссылки

Якорь - ссылка внутри одной страницы. Используется для оглавлений и навигации по длинному тексту.

Сначала ставим id на элемент, к которому хотим перейти: 

<h2 id="about">Обо мне</h2>
<h2 id="contacts">Контакты</h2>

Потом делаем ссылку на этот id - со знаком #: 

<a href="#about">Перейти к разделу «Обо мне»</a>
<a href="#contacts">Перейти к контактам</a>

При клике браузер прокрутит страницу к нужному разделу. Если страница длинная - без таких ссылок не обойтись.

Правило: id должен быть уникальным на странице. Два элемента с одинаковым id - ошибка.

Якорь на другую страницу

Можно ссылаться не просто на страницу, а сразу на раздел в ней:

<a href="about.html#biography">Биография</a>

Ссылка на почту и телефон

<a href="mailto:ivan@example.com">Написать мне</a>
<a href="tel:+79000000000">Позвонить</a>

При клике на первую откроется почтовый клиент с адресом. При клике на вторую - телефон позвонит по номеру (на смартфоне).

Атрибут target - открыть в новой вкладке

<a href="https://yandex.ru" target="_blank">Яндекс в новой вкладке</a>

_blank - «новая вкладка». По умолчанию ссылка открывается в текущей вкладке.

Правило: используйте target="_blank" только для внешних ссылок. Внутри своего сайта - нет. Пользователь сам решит, открыть в новой вкладке или нет.

Ссылка-картинка

Ссылкой может быть не только текст, но и картинка:

<a href="https://github.com/username">
    <img src="images/github.png" alt="Мой GitHub" width="50">
</a>

Клик по картинке приведёт на указанный адрес. Часто используется для иконок соцсетей.

Итоговая таблица

Что Пример
Абсолютная ссылка href="https://yandex.ru"
Относительная ссылка href="about.html"
Ссылка на уровень выше href="../index.html"
Якорь на этой странице href="#about"
Якорь на другой странице href="about.html#bio"
Ссылка на почту href="mailto:ivan@mail.ru"
Ссылка на телефон href="tel:+79000000000"
Открыть в новой вкладке target="_blank"

8. Изображения

Тег img

<img src="images/photo.jpg" alt="Описание картинки" width="300">

<img> - одиночный тег. Обязательные атрибуты:

Атрибут Что значит
src Путь к картинке (относительный или абсолютный)
alt Описание. Показывается, если картинка не загрузилась. Читают скринридеры
width Ширина в пикселях
height Высота в пикселях

figure и figcaption - подпись к картинке

<figure>
    <img src="images/poster.jpg" alt="Постер фильма" width="300">
    <figcaption>Постер фильма, 2014 год</figcaption>
</figure>

<figure> - контейнер для картинки, <figcaption> - подпись. Это семантический способ: браузер, поисковик и скринридер понимают, что подпись относится именно к картинке.

9. Устаревшие теги и атрибуты

Это история. Эти теги и атрибуты не используются в современной разработке. Они существовали, когда ещё не было CSS, и оформление вешали прямо в HTML. Знать их нужно, чтобы понимать старый код и осознавать, зачем появился CSS.

Устаревшее Что делало Современная замена
<font> Шрифт, цвет, размер CSS: font, color
align Выравнивание CSS: text-align
bgcolor Цвет фона CSS: background-color
background Фоновая картинка CSS: background-image
border Рамка CSS: border
width / height Размеры CSS (кроме <img>)

Все эти теги и атрибуты убрали, потому что они смешивали разметку и оформление. А оформление - это задача CSS.

10. Таблицы

Таблицы используются для отображения табличных данных: расписаний, прайсов, сравнений, статистики. У этих данных есть строки и столбцы, и таблица - естественный способ их показать.

Важно: таблицы - только для данных, не для макета. Раньше, когда не было CSS, разработчики строили всю вёрстку сайта на таблицах. Сейчас так никто не делает: для макета есть CSS. Если у данных нет логики «строки и столбцы» - таблица не нужна.

Базовая структура

Таблица состоит из трёх базовых тегов:

  • <table> - контейнер всей таблицы
  • <tr> - строка таблицы (table row)
  • <td> - ячейка с данными (table data) 
<table border="1">
    <tr>
        <td>Ячейка 1</td>
        <td>Ячейка 2</td>
    </tr>
    <tr>
        <td>Ячейка 3</td>
        <td>Ячейка 4</td>
    </tr>
</table>

Заголовочные ячейки: th

Для шапки таблицы есть отдельный тег - <th> (table header). Он делает текст жирным и выравнивает по центру, но главное - говорит браузеру, скринридеру и поисковику, что это заголовок столбца. 

<table border="1">
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
        <th>Город</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>25</td>
        <td>Москва</td>
    </tr>
    <tr>
        <td>Мария</td>
        <td>30</td>
        <td>Санкт-Петербург</td>
    </tr>
</table>

Объединение ячеек: colspan и rowspan

Иногда нужно, чтобы ячейка занимала несколько столбцов или строк. Для этого есть два атрибута:

  • colspan (column span) - объединение по горизонтали
  • rowspan (row span) - объединение по вертикали

colspan - по горизонтали

<table border="1">
    <tr>
        <th colspan="3">Список студентов</th>
    </tr>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
        <th>Город</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>25</td>
        <td>Москва</td>
    </tr>
</table>

colspan="3" - ячейка займёт три столбца вместо одного.

rowspan - по вертикали

<table border="1">
    <tr>
        <th>День</th>
        <th>Занятие</th>
    </tr>
    <tr>
        <td rowspan="2">Понедельник</td>
        <td>HTML</td>
    </tr>
    <tr>
        <td>CSS</td>
    </tr>
</table>

rowspan="2" - ячейка займёт две строки. Обратите внимание: во второй строке остаётся только одна ячейка, потому что первая уже занята «Понедельником» сверху.

Правило: если ячейка занимает несколько строк или столбцов - в следующих строках/столбцах её не пишем. Место уже занято.

Семантические части: thead, tbody, tfoot

Таблицу можно разбить на три логические части:

  • <thead> - шапка (заголовки столбцов)
  • <tbody> - тело (основные данные)
  • <tfoot> - подвал (итоги, примечания)
<table border="1">
    <thead>
        <tr>
            <th>Товар</th>
            <th>Цена</th>
            <th>Количество</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Хлеб</td>
            <td>50 ₽</td>
            <td>2</td>
        </tr>
        <tr>
            <td>Молоко</td>
            <td>80 ₽</td>
            <td>1</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="2">Итого:</td>
            <td>180 ₽</td>
        </tr>
    </tfoot>
</table>

Зачем это нужно:

  • Скринридеры понимают, где шапка, где данные, где итоги - незрячий пользователь может «перейти к итогам» или «прочитать шапку»
  • Поисковики лучше понимают структуру таблицы
  • CSS (когда вы его изучите) позволяет стилизовать части отдельно - например, закрепить шапку при прокрутке

Изображение внутри ячейки

В ячейку можно поместить не только текст, но и картинку через <img>. Используется для каталогов, меню, галерей: 

<table border="1">
    <tr>
        <th>Фото</th>
        <th>Товар</th>
        <th>Цена</th>
    </tr>
    <tr>
        <td><img src="bread.jpg" alt="Хлеб" width="100"></td>
        <td>Хлеб</td>
        <td>50 ₽</td>
    </tr>
</table>

Ячейка растягивается под размер картинки - как обычный контейнер.

Устаревшие атрибуты для таблиц

Это история. Раньше размеры и отступы таблицы задавали прямо в HTML. Сейчас это делается через CSS, но на занятиях может пригодиться.

Атрибут Что делал Современная замена
border Рамка вокруг ячеек CSS: border
width / height Размер таблицы CSS: width, height
cellpadding Отступ внутри ячейки CSS: padding
cellspacing Отступ между ячейками CSS: border-spacing
bgcolor Цвет ячейки CSS: background-color

11. Формы

Формы - это способ, которым сайт общается с пользователем. Регистрация, вход, поиск, отзывы, оформление заказа - всё это формы. Пользователь заполняет поля, нажимает кнопку - данные уходят на сервер.

Контейнер формы

<form action="/submit" method="POST">
    <!-- поля формы -->
</form>

Два главных атрибута:

  • action - куда отправить данные (адрес сервера или скрипта)
  • method - как отправить: GET или POST

Зачем нужен form

Три причины оборачивать поля в <form>:

  • Кнопка submit работает только внутри формы. Без формы она превращается в обычную кнопку-пустышку
  • Форма собирает данные в один набор. Все поля внутри одной формы отправляются вместе
  • Форма знает, куда и как отправлять - через action и method
Важно: обычное поле <input> без формы работает - пользователь может в него писать. Просто данные никуда не уходят. Как только нужна отправка - нужна <form>.

GET и POST: в чём разница

GET - данные отправляются в адресной строке:

https://example.com/search?query=html&lang=ru

Всё, что после ? - это данные формы. Их видно всем.

POST - данные отправляются в теле запроса, в адресе их не видно.

Метод Когда использовать Пример
GET Поиск, фильтры. Данные не секретные Поиск в Google
POST Логин, регистрация, оплата. Данные секретные Вход в банк
Правило: если данные можно показать в адресной строке - GET. Если это пароли, личная информация, деньги - POST.

Поля ввода: input

Основной тег для полей - <input>. Это одиночный тег. Главный атрибут - type, он определяет вид поля. 

<input type="text" name="username">

Атрибут name: зачем он нужен

Когда пользователь нажимает «Отправить», браузер собирает данные формы и отправляет их на сервер в виде пар «имя=значение»: 

username=Иван&email=ivan@mail.ru&city=msk

Здесь username, email, city - это то, что написано в атрибуте name. А Иван, ivan@mail.ru, msk - то, что ввёл пользователь.

Правило: нет name - нет данных. Поле останется на странице, пользователь его заполнит, но на сервер оно не уйдёт.

name и value - разные вещи

  • name - имя поля. Задаёт разработчик. Одинаковое для всех полей этого типа
  • value - значение. У текстовых полей его вводит пользователь. У чекбоксов, радиокнопок и <option> - задаёт разработчик 
<input type="radio" name="gender" value="male"> Мужской

Пользователь видит «Мужской». На сервер уходит male - потому что так написано в value. А имя поля - gender, чтобы сервер понял: это ответ на вопрос про пол.

Основные типы полей

Тип Что это Пример использования
text Обычный текст Имя, логин
password Пароль (символы скрыты) Пароль
email Email с проверкой на @ Почта
number Число (можно min и max) Возраст
date Дата с календариком День рождения
checkbox Галочка (можно выбрать несколько) Увлечения
radio Кружок (только один из группы) Пол
file Загрузка файла Аватар

Чекбоксы и радиокнопки

Checkbox - можно выбрать несколько:

<input type="checkbox" name="hobby" value="sport"> Спорт
<input type="checkbox" name="hobby" value="music"> Музыка

Radio - только один из группы. У всех радиокнопок группы одинаковый name: 

<input type="radio" name="gender" value="male"> Мужской
<input type="radio" name="gender" value="female"> Женский

Атрибут value - значение, которое уйдёт на сервер. Пользователь видит «Спорт», на сервер уходит sport.

Выпадающий список: select

<select name="city">
    <option value="">-- Выберите город --</option>
    <option value="msk">Москва</option>
    <option value="spb">Санкт-Петербург</option>
</select>

<select> - контейнер, <option> - один вариант. Первый <option> с пустым value часто используют как подсказку.

Многострочное поле: textarea

<textarea name="message" rows="5" cols="30"></textarea>

Для длинных текстов: отзывов, комментариев. rows - количество строк, cols - ширина в символах. <textarea> - парный тег, начальный текст пишется между тегами.

Label - подпись к полю

Два способа связать подпись с полем:

<label>Имя: <input type="text" name="username"></label>

Или через атрибут for:

<label for="username">Имя:</label>
<input type="text" id="username" name="username">

for в <label> должен совпадать с id в поле. Тогда клик по тексту подписи ставит курсор в поле. Это удобно и важно для доступности.

Второй способ без for: можно обернуть <input> внутрь <label> - тогда for и id не нужны. Связь работает автоматически.

Кнопки

Три типа кнопок:

  • <button type="submit"> - отправить форму
  • <button type="reset"> - очистить все поля
  • <button type="button"> - кнопка-заготовка, действие программируется через JavaScript 
<button type="submit">Отправить</button>
<button type="reset">Очистить</button>

Полезные атрибуты полей

Атрибут Что делает
placeholder Серая подсказка внутри поля. Исчезает при вводе
required Поле обязательно для заполнения. Браузер не даст отправить форму без него
value Начальное значение поля
disabled Поле отключено, нельзя редактировать
readonly Только для чтения. Можно выделить, но не редактировать

accept - для загрузки файлов

<input type="file" name="avatar" accept="image/*">

Фильтр для диалога выбора файла. Без accept можно выбрать любой файл. С ним - только указанные типы:

Что нужно Как написать
Любые картинки accept="image/*"
Любое видео accept="video/*"
Любой звук accept="audio/*"
Только PDF accept=".pdf"
Документы Word accept=".doc,.docx"
Полезно знать: атрибут multiple позволяет выбрать несколько файлов сразу. А capture - открыть камеру на телефоне.

12. Введение в CSS

CSS (Cascading Style Sheets, каскадные таблицы стилей) - язык, который описывает, как выглядит страница: цвета, шрифты, размеры, отступы, расположение блоков.

HTML отвечает за структуру и смысл: заголовок, абзац, список, ссылка. CSS отвечает за внешний вид. Один и тот же HTML можно оформить сотней разных способов, не меняя ни одного тега.

Главная идея: содержание отдельно, оформление отдельно. HTML говорит что это, CSS - как это выглядит.

Три способа подключить CSS

1. Внешний файл - основной способ

Стили лежат в отдельном файле style.css, а в <head> страницы добавляется одна строка: 

<link rel="stylesheet" href="style.css">

Это лучший способ для проекта: один файл стилей можно подключить ко всем страницам сайта. Изменили цвет в одном месте - он поменялся везде.

2. Внутренние стили - тег style

Правила пишут прямо в <head> внутри тега <style>: 

<style>
    h1 {
        color: #1f4e5f;
    }
</style>

Удобно для одной страницы или быстрого эксперимента. Для сайта из нескольких страниц не подходит: стили придётся повторять в каждой.

3. Inline-стили - атрибут style

Стиль записывается прямо в тег:

<p style="color: #b03a2e;">Красный текст</p>

Такой стиль действует только на один элемент и перебивает почти все остальные правила. В учебном проекте inline-стили не используем: их трудно найти и изменить.

Способ Где живёт Когда использовать
Внешний файл style.css Всегда в проекте: один файл на весь сайт
Внутренний <style> в <head> Одна страница, быстрый опыт
Inline Атрибут style Почти никогда: только для проверки

Синтаксис правила

Правило CSS состоит из селектора и блока объявлений:

селектор {
    свойство: значение;
    свойство: значение;
}
  • Селектор - какой элемент выбираем
  • Свойство - что меняем
  • Значение - на что меняем

Например:

h1 {
    color: #1f4e5f;
    font-size: 40px;
}

Это правило выбирает все заголовки h1 и делает их тёмно-зелёными размером 40 пикселей.

Частая ошибка: забыть точку с запятой ; после объявления или фигурную скобку } в конце блока. Тогда следующее правило может не сработать.

Базовые селекторы

Селектор Запись в CSS Что выбирает Пример HTML
По тегу p Все абзацы на странице <p>Текст</p>
По классу .lead Все элементы с классом lead <p class="lead">Текст</p>
По id #facts Один элемент с id facts <aside id="facts">...</aside>

В CSS класс записывается с точкой, id - с решёткой. В HTML точка и решётка не пишутся: там просто class="lead" и id="facts".

Группировка и вложенные селекторы

Если нескольким элементам нужны одинаковые свойства, селекторы можно перечислить через запятую: 

h1,
h2 {
    color: #1f4e5f;
}

Это правило применится и к h1, и к h2. Запятая читается как «и».

Вложенный селектор выбирает элементы только внутри другого блока. Селекторы разделяются пробелом: 

header a {
    text-decoration: none;
}

Читается так: «найди header, а внутри него - все a». Ссылки в основном тексте и в подвале это правило не затронет.

Группировку и вложенность можно совмещать:

header a,
footer a {
    text-decoration: none;
}
Не путайте: h1, h2 - «и первый, и второй заголовок», а h1 h2 - «заголовок второго уровня внутри первого». Запятая и пробел дают разный результат.

Сила селекторов

Если на один элемент действуют несколько правил, побеждает более сильное. Порядок такой: 

id  →  класс  →  тег

Самый сильный - id, самый слабый - тег. Inline-стиль сильнее всех.

<p class="lead" id="intro">Текст</p>
p      { color: #222222; }  /* слабее всех */
.lead  { color: #1f4e5f; }  /* сильнее тега */
#intro { color: #b03a2e; }  /* победит */

Поэтому один и тот же класс можно использовать на разных страницах: там, где он не нужен, он просто не сработает.

Базовые свойства текста

Свойство Что делает Пример
color Цвет текста color: #2d3142;
background-color Цвет фона background-color: #f7f2e7;
font-family Шрифт font-family: Georgia, serif;
font-size Размер шрифта font-size: 18px;
line-height Межстрочный интервал line-height: 1.6;
text-align Выравнивание текста text-align: center;
text-decoration Подчёркивание text-decoration: none;

Цвет можно записывать кодом #rrggbb, например #1f4e5f: первые две цифры отвечают за красный, следующие две - за зелёный, последние две - за синий.

Комментарии в CSS

Комментарий начинается с /* и заканчивается */. Браузер его не читает, а человек понимает, зачем написано правило: 

/* Фон и основной шрифт всей страницы */
body {
    background-color: #f7f2e7;
    color: #2d3142;
}

Пишите короткие комментарии к каждой группе правил. Через месяц вы скажете себе спасибо.

Как проверить стили в браузере

  1. Откройте страницу и нажмите F12 или Ctrl + Shift + I.
  2. Щёлкните по элементу в коде.
  3. На панели Styles видно, какие правила применились. Зачёркнутые правила перебиты более сильными.

Частые ошибки

Проблема Что проверить
Стили не применились Путь в href, имя файла, <link> внутри <head>
В браузере виден код CSS Открыт style.css, а не index.html
Класс не работает В HTML class="lead", в CSS .lead с точкой
id не работает В HTML id="facts", в CSS #facts с решёткой
Группировка не работает Между селекторами нужна запятая: h1, h2, а не h1 h2
Вложенный селектор не работает Между селекторами нужен пробел: header a, а не header, a
Правило не работает Точка с запятой в конце объявления, двоеточие после свойства, скобка в конце блока
Файл не сохранился Ctrl + S, затем F5 или Ctrl + F5
