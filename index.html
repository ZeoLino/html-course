1. Что такое HTML

HTML (HyperText Markup Language) - язык гипертекстовой разметки. Это не язык программирования, а язык разметки: мы помечаем текст тегами, чтобы браузер знал, что где находится.

HTML-файл - это обычный текстовый файл с расширением .html. Браузер его читает и превращает в страницу.

В веб-разработке есть три технологии:

  • HTML - скелет, структура
  • CSS - внешний вид, оформление
  • JavaScript - поведение, интерактивность

2. Структура документа

Каждый HTML-документ состоит из обязательных частей:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Заголовок страницы</title>
</head>
<body>
    Содержимое страницы
</body>
</html>

Разбор каждой части

Часть Что значит
<!DOCTYPE html> Декларация: «это современный HTML». Пишется первой строкой
<html> Корневой элемент. Всё содержимое внутри. Сюда вешают атрибут lang
<head> Служебная часть. Пользователь её не видит
<body> Всё, что видно на странице
Важно: тег <html> нужен не только как «коробка». На него вешают атрибуты - самый частый lang. Без него некуда будет указать язык страницы.

3. Метаданные

Внутри <head> лежат метаданные - служебная информация для браузера и поисковиков. Пользователь её не видит, кроме <title>.

charset - кодировка

<meta charset="UTF-8">

Указывает кодировку файла. Всегда пишем UTF-8 - это современная кодировка, в которой есть все буквы мира.

Правило: кодировка файла и <meta charset> должны совпадать. Если сказать браузеру «я UTF-8», а файл сохранить в ANSI - получишь кракозябры.

viewport - для мобильных

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Говорит браузеру: «считай ширину экрана реальной шириной устройства». Без этого на телефоне страница будет уменьшенной копией десктопной.

description - описание

<meta name="description" content="Личная страница Ивана">

Описание страницы. Пользователь его не видит на странице, но видит в поисковой выдаче - серым текстом под заголовком.

Нюанс: description - это рекомендация, а не приказ. Google может проигнорировать ваш текст и собрать описание сам из содержимого страницы.

title - заголовок вкладки

<title>Моя первая страница</title>

Единственный элемент из <head>, который видит пользователь - на вкладке браузера. Также используется поисковиками.

4. Текст

Заголовки

Шесть уровней: от <h1> до <h6>. 

<h1>Главный заголовок</h1>
<h2>Раздел</h2>
<h3>Подраздел</h3>
Правила:
  • На странице только один <h1>
  • Нельзя перескакивать уровни: после h1 идёт h2, не h4

Абзацы и переносы

<p>Это абзац текста.</p>

<p>Первая строка<br>Вторая строка</p>

<p> - абзац, <br> - перенос строки внутри абзаца. Перенос строки в коде браузер игнорирует.

5. Форматирование текста

Теги делятся на семантические (описывают смысл) и визуальные (описывают вид).

Семантические теги

<strong>Важный текст</strong>
<em>Акцент, интонация</em>
<mark>Выделенное, искомое</mark>
<small>Второстепенная информация</small>
<del>Удалённый текст</del>
<ins>Добавленный текст</ins>
<sub>Нижний индекс</sub>
<sup>Верхний индекс</sup>

Визуальные теги

<b>Жирный</b>
<i>Курсив</i>

pre - текст как в коде

<pre>
Строка 1
    Строка 2 с отступом
</pre>

Сохраняет переносы строк и пробелы ровно так, как написано в коде.

Комментарии

<!-- Это комментарий -->

Не виден на странице, но виден в исходном коде. Используется для пометок, объяснений и временного отключения кода.

6. Списки

Маркированный список

<ul>
    <li>Хлеб</li>
    <li>Молоко</li>
    <li>Яйца</li>
</ul>

Порядок не важен. Каждый пункт с маркером.

Нумерованный список

<ol>
    <li>Разбейте яйца</li>
    <li>Взбейте с молоком</li>
    <li>Добавьте муку</li>
</ol>

Порядок важен. Каждый пункт с числом.

Вложенные списки

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
</ul>

Вложенный список кладётся внутрь <li>.

Список описаний

<dl>
    <dt>HTML</dt>
    <dd>Язык разметки гипертекста</dd>
    
    <dt>CSS</dt>
    <dd>Язык описания внешнего вида</dd>
</dl>

Пары «термин - определение»: <dt> - термин, <dd> - определение.

Когда какой использовать

Список Когда использовать
<ul> Порядок не важен: список покупок, навыков
<ol> Порядок важен: инструкция, рецепт, шаги
<dl> Пары «термин - определение»: словарь, глоссарий

7. Ссылки

Слово «гипертекст» в названии HTML - это про ссылки. Гипертекст - это текст, по которому можно переходить. Ссылки - то, что делает интернет интернетом. Без них была бы просто куча отдельных страниц.

Тег a и атрибут href

<a href="https://yandex.ru">Перейти на Яндекс</a>

Ссылка делается тегом <a> - anchor, «якорь». Адрес, куда ведёт ссылка, указывается в атрибуте href - hypertext reference.

<a> - парный тег. Текст между <a> и </a> - то, что видит пользователь. Атрибут href - куда ведёт ссылка.

Абсолютные ссылки

Полный адрес с протоколом:

<a href="https://www.google.com">Google</a>
<a href="https://github.com">GitHub</a>

Обязательно с https:// (или http://). Без протокола браузер подумает, что это относительная ссылка.

Относительные ссылки

Адрес относительно текущего файла. Используется для ссылок между страницами своего сайта.

Представьте такую структуру:

lesson-3/
├── index.html
├── about.html
└── contacts.html

Тогда ссылки между ними:

<!-- В файле index.html -->
<a href="about.html">Обо мне</a>
<a href="contacts.html">Контакты</a>

Заметьте: не https://..., а просто about.html. Браузер сам поймёт, что файл лежит рядом с текущим.

Если файл в другой папке

<!-- Файл в подпапке pages -->
<a href="pages/about.html">Обо мне</a>

<!-- Файл на уровень выше -->
<a href="../index.html">На главную</a>

../ означает «выйти на уровень выше».

Абсолютные vs относительные: какую выбирать

Ситуация Какую ссылку использовать
Ссылка на внешний сайт Абсолютная: https://yandex.ru
Ссылка внутри своего сайта Относительная: about.html
Почему не всегда абсолютные? Если сайт переедет на другой домен, все абсолютные ссылки придётся менять вручную. А относительные продолжат работать.

Якорные ссылки

Якорь - ссылка внутри одной страницы. Используется для оглавлений и навигации по длинному тексту.

Сначала ставим id на элемент, к которому хотим перейти: 

<h2 id="about">Обо мне</h2>
<h2 id="contacts">Контакты</h2>

Потом делаем ссылку на этот id - со знаком #: 

<a href="#about">Перейти к разделу «Обо мне»</a>
<a href="#contacts">Перейти к контактам</a>

При клике браузер прокрутит страницу к нужному разделу. Если страница длинная - без таких ссылок не обойтись.

Правило: id должен быть уникальным на странице. Два элемента с одинаковым id - ошибка.

Якорь на другую страницу

Можно ссылаться не просто на страницу, а сразу на раздел в ней:

<a href="about.html#biography">Биография</a>

Ссылка на почту и телефон

<a href="mailto:ivan@example.com">Написать мне</a>
<a href="tel:+79000000000">Позвонить</a>

При клике на первую откроется почтовый клиент с адресом. При клике на вторую - телефон позвонит по номеру (на смартфоне).

Атрибут target - открыть в новой вкладке

<a href="https://yandex.ru" target="_blank">Яндекс в новой вкладке</a>

_blank - «новая вкладка». По умолчанию ссылка открывается в текущей вкладке.

Правило: используйте target="_blank" только для внешних ссылок. Внутри своего сайта - нет. Пользователь сам решит, открыть в новой вкладке или нет.

Ссылка-картинка

Ссылкой может быть не только текст, но и картинка:

<a href="https://github.com/username">
    <img src="images/github.png" alt="Мой GitHub" width="50">
</a>

Клик по картинке приведёт на указанный адрес. Часто используется для иконок соцсетей.

Итоговая таблица

Что Пример
Абсолютная ссылка href="https://yandex.ru"
Относительная ссылка href="about.html"
Ссылка на уровень выше href="../index.html"
Якорь на этой странице href="#about"
Якорь на другой странице href="about.html#bio"
Ссылка на почту href="mailto:ivan@mail.ru"
Ссылка на телефон href="tel:+79000000000"
Открыть в новой вкладке target="_blank"

8. Изображения

Тег img

<img src="images/photo.jpg" alt="Описание картинки" width="300">

<img> - одиночный тег. Обязательные атрибуты:

Атрибут Что значит
src Путь к картинке (относительный или абсолютный)
alt Описание. Показывается, если картинка не загрузилась. Читают скринридеры
width Ширина в пикселях
height Высота в пикселях

figure и figcaption - подпись к картинке

<figure>
    <img src="images/poster.jpg" alt="Постер фильма" width="300">
    <figcaption>Постер фильма, 2014 год</figcaption>
</figure>

<figure> - контейнер для картинки, <figcaption> - подпись. Это семантический способ: браузер, поисковик и скринридер понимают, что подпись относится именно к картинке.

9. Устаревшие теги

Это история. Эти теги и атрибуты не используются в современной разработке. Они существовали, когда ещё не было CSS, и оформление вешали прямо в HTML. Знать их нужно, чтобы понимать старый код и осознавать, зачем появился CSS.

Устаревшее Что делало Современная замена
<font> Шрифт, цвет, размер CSS: font, color
align Выравнивание CSS: text-align
bgcolor Цвет фона CSS: background-color
background Фоновая картинка CSS: background-image
border Рамка CSS: border
width / height Размеры CSS (кроме <img>)

Все эти теги и атрибуты убрали, потому что они смешивали разметку и оформление. А оформление - это задача CSS.
